Controls

Controls are indigo, not violet — violet is reserved for state that the map reflects back at you. A switch that turns a layer on is structure; a selected tool is state.

Switches

Layers

34 × 19 track, 13px knob, 15px travel. The whole row is the label and the hit target — hover lifts the row name from 50% to 70%, never the switch alone.

Segmented

Pill inside a pill. The active segment is solid white on dark — the same inversion the primary button uses, so “selected” reads identically everywhere.

Two stacked inputs with pointer-events handed to the thumbs only, so the invisible tracks don't fight each other.

Tool rail

Left edge, vertically centred, 16px inset. Buttons are flush — the rail's 10px radius and overflow:hidden do the rounding, so no button carries its own corner.
